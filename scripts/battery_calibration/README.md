# Battery calibration pipeline

## 1. `ina219.ino`
This calibration mechanism measures battery characteristics out-of-band, using
a custom testbed, not the BSB device itself.

This testbed consists of:
  - A microcontroller that Arduino IDE can compile firmware for;
  - An INA219 power meter module (measures current and voltage);
  - Battery itself;
  - Power supply with CC/CV capability;
  - Smart load / electronic load with CC capability;
  - Wires.

This Arduino sketch acquires data from the power meter module and streams them
to the host computer via UART over USB.

## 2. `collect.py`
Receives time, current and voltage data from the testbed and logs them to a
file for future processing.

## 3. `plot.py`
  1. Reads data acquired by `collect.py` from a file;
  2. Integrates the current curve to get the charge curve;
  3. Picks current/voltage pairs at different State-of-Charge points (0..100%
     with 1% step) and prints them to the console for future processing;
  4. Plots a 2D graph of voltage, current and charge over time.

## 4. `plot_cal.py`
  1. Takes several I-and-V-vs-charge curves at different currents generated by
     `plot.py`;
  2. Aggregates this data, the more curves - the better;
  3. Plots a 3D graph of voltage vs State-of-Charge and current, which is the
     final result of this entire process;
  4. Exports this graph in a custom machine-readable format (`.bat_cal`)

## 5. `live_test.py`
  1. Reads calibration profile from `.bat_cal` file generated by `plot_cal.py`;
  2. Listens to current and voltage data from Arduino;
  3. Infers State-of-Charge using the calibration profile in real time;

If results of `live_test.py` are satisfactory, the calibration profile can be
uploaded to the BSB device and tested there.
