# Main applications

## Applications corresponding to a mode switch position:

| Name            | Position   | Purpose |
| --------------- | ---------- | ------- |
| `busy`          | `BUSY`     | The BUSY timer. |
| -               | `CUSTOM`   | - |
| `soft_off`      | `OFF`      | Power-down mode. |
| `apps_menu`[^1] | `APPS`     | The main applications menu or the last used application. |
| `settings_menu` | `SETTINGS` | The settings menu. |

[^1]: TODO: place `apps_menu` to this folder

## Extra applications accessible from the `APPS` menu:

| Name | Purpose |
| ---- | ------- |
| `clock` | A full-screen clock with some customisation. |
