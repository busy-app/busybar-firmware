# Applications

BUSY Status Bar applications are divided into several categories:

- `main` - The applications that are available via the mode switch or the "Applications" menu.
- `services` - Background services that provide base functionality to the applications.
- `settings` - Special applications that implement settings categories (e.g. Bluetooth or Wi-Fi settings).
- `system` - Special applications that are not directly accessible by the user (without using the CLI), but are used internally by the system.
- `debug` - Various tests and demos, available from the "Debug Apps" menu if the developer mode is on.
