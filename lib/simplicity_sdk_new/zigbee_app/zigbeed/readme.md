# Zigbeed Host Application


Zigbeed is a Zigbee Stack daemon that runs on a Linux host processor.
It communicates with an 802.15.4 RCP via CPCd, and exposes an EZSP interface to a Zigbee host app. See *https://docs.silabs.com/multiprotocol/latest/multiprotocol-solution-linux/ Running Zigbee, OpenThread, and Bluetooth Concurrently on a Linux Host with a Multiprotocol RCP* for more information.
