# Silicon Labs' Compute Package

[![Silicon Labs](./doc/images/silabs-logo.jpg)](https://www.silabs.com)

The Silicon Labs Compute Package provides an application programming interface (API) to enable power-efficient hardware acceleration of math operations for computational tasks on Silicon Labs' Series 2 and SiWx917 family of parts. Silicon Labs' AI/ML Package relies on this package to provide underlying math implementations for executing Machine Learning models.
