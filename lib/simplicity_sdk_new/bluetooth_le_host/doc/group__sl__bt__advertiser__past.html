Detailed Description

Advertiser PAST.

Transfer the synchronization information of a local active periodic advertising set to a remote device using Periodic Advertising Synchronization Transfer (PAST) over a connection.

Transfer the synchronization information of an advertising set that is actively performing periodic advertising. The transfer happens over a Periodic Advertising with Responses (PAwR) train.

Parameters
[in]transferring_advertising_setThe handle of the PAwR advertising set used to transfer the synchronization information to the synchronized devices.
[in]service_dataA value provided by the application for use by the peer device.
[in]advertising_setHandle of the periodic advertising set to transfer
[in]repeat_countThe number of times the synchronization information is sent on the specified subevents of transferring_advertising_set.
  • Range: 0x01 to 0xFF
[in]subevents_lenLength of data in subevents
[in]subeventsArray of subevent indexes in which to send the synchronization information. If a zero-length array is provided, the synchronization information is sent in all subevents of transferring_advertising_set.
Returns
SL_STATUS_OK if successful. Error code otherwise.
