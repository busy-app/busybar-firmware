Detailed Description

This event is triggered if subevent data was successfully set using sl_bt_pawr_advertiser_set_subevent_data command but the attempt to transmit the subevent data has failed.

This error is not fatal. The event is provided to the application so that it knows not to expect response reports for this subevent and can set subevent data again for retransmission without needing to timeout waiting for response reports that will not be received because the transmission failed.
