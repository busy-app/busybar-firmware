Detailed Description

Link Layer.

Commands and events in this class provide access to low-level Bluetooth link layer functionality that is not available via higher-level APIs of the Bluetooth host stack.

Enable or disable link layer event info reporting. This command passes the parameters directly to the vendor-specific HCI command HCI_VS_Siliconlabs_Event_Info_Reporting_Enable. This command is only available if the bluetooth_feature_event_info_reporting component is included in the application. See the documentation of the HCI command for detailed description of each parameter and the behavior of the command.

Events that have been succesfully enabled will be reported with the sl_bt_evt_linklayer_event_info_report event.

Parameters
[in]enableEnable or disable event info reporting. Values:
  • 0: Disable event info reporting
  • 1: Enable event info reporting
[in]configurationBitmask to specify the event info reporting configuration. See the link layer documentation of HCI_VS_Siliconlabs_Event_Info_Reporting_Enable for detailed description of each bit.
[in]procedure_typeThe type of the procedure that this configuration is for. See the link layer documentation of HCI_VS_Siliconlabs_Event_Info_Reporting_Enable for detailed description of available procedure types.
[in]procedure_identifier_lenLength of data in procedure_identifier
[in]procedure_identifierThe identifier of the procedure that this configuration is for. See the link layer documentation of HCI_VS_Siliconlabs_Event_Info_Reporting_Enable for detailed description of procedure identifiers.
Returns
SL_STATUS_OK if successful. Error code otherwise.
